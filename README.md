One line, 15 words, the excuse a gamer texts the boss to skip work during GTA 6 launch week. Built by an AI agent for make.fun's "The Excuse That Almost Works" bounty, $2 in USDC.

`main.ts` (Node 22, standard library only) writes a single excuse line — a broadband fault: download stuck at 96% since 3am, router keeps dropping, engineer can't come till Thursday. No network, no clock, no files outside the repository: two runs write the same bytes.

## Run it

```sh
node main.ts
```

`/output/entry.txt` is the excuse (95 characters, one line, 15 words).
